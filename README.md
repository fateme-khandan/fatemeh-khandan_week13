# React Tabs Component

A simple and responsive Tabs Component built with React.

## Features
- Four interactive tabs
- Dynamic content switching
- Active tab styling
- Save the last selected tab using LocalStorage
- Responsive design

## Technologies
- React
- JavaScript
- CSS
- Vite

## Getting Started

Install dependencies:

npm install

Run the development server:

npm run dev
